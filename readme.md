# Numenius Argutus

Система мониторинга и прогнозирования угроз (БПЛА, ракеты) на основе текстовых сообщений из Telegram-каналов.

## Архитектура

- **Numenius.App** — консольное приложение (точка входа).
- **Numenius.Core** — основная библиотека с логикой.

### Основные компоненты

- **Источники**: перехват Toast-уведомлений Windows (Telegram), ручной ввод, импорт JSON.
- **Обработка сообщений**: NlpParser (извлечение типа угрозы, населённых пунктов, статуса), MessageProcessor.
- **Управление инцидентами**: ScenarioManager (создание, обновление, закрытие, разделение дронов).
- **Зоны**: ZoneService (создание, пересечение, кластеризация).
- **Прогнозирование**: BayesianPredictor (вероятностный подход на основе зон и исторических переходов).
- **Вывод**: консоль, TTS, MQTT.

## Технологии

- .NET 8 (Windows 10/11)
- SQLite (хранение данных)
- System.Speech (TTS)
- Windows Toast Notifications API
